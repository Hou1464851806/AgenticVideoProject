## Vue 接入结果

### 结构

- `ProjectWorkspace.vue` 负责三栏外壳、项目切换、素材摘要、抽屉/播放器/用量弹窗、URL 恢复和窄屏自动折叠。
- `WorkspaceRail.vue` 承载项目切换器、会话列表、素材摘要、用量/诊断/账户；真实账户项目较多，因此用可滚动项目切换器替代原型里的项目长列表，让当前项目的会话始终可见。
- `AssetDrawer.vue` 用 560px 左侧抽屉承载 `AssetLibrary`、`UploadPanel` 与 `SpeechSearch`；媒体播放改为居中弹窗。
- 上传入口改为与原型一致的虚线 dropzone（按钮 + 隐藏原生 file input）：可点击、可拖入，原生「选择文件」控件不再直接露出；上传、暂停、恢复逻辑不变。
- `ConversationPanel.vue` 改为单列对话：草稿卡、预览记录、追问回答框都在消息流内；移除了旧的三页签和右侧详情列。
- `PlanPanel.vue` 作为右侧 380px 可折叠产物面板，切换会话时清理上一个会话的预览/导出展示，避免残留。
- `DraftCard.vue` 增加「暂不采纳」UI 收起，不调用不存在的拒绝接口；确认后草稿只读。

### 真实行为

- 项目切换、新建项目、新聊天、发送、停止、重试、草稿预览、确认全部输出、追问回答、素材上传/检索/播放、用量、诊断、左右折叠均复用现有接口。
- 追问改为读取快照的 `questions` 字段；旧实现只读 `agent.pendingQuestions`，会漏掉当前后端真正打开的追问。回答调用 `POST /conversations/{id}/questions/{questionId}/answers`。
- 右侧面板只展示当前会话的预览和当前版本导出；切换会话/项目会清空上一会话的固定预览/导出块。
- 窄屏（≤1180）自动收起产物面板，≤900 自动收起工作区；两侧仍可手动展开。

## 用户与主线

面向使用视频素材做问答和剪辑的内容创作者、内容团队。首屏要能继续一段对话，看到 Agent 的剪辑草稿和待回答的问题；同时知道素材在哪、哪些方案已确认、渲染进行到哪一步。

```text
导入素材 → 与 Agent 多轮对话 → 收到剪辑草稿
         → 预览低清版 / 确认全部输出 / 暂不采纳
         → 在右侧看到已确认方案与当前版本
         → 发起 720p / 1080p 导出并查看运行中任务
```

设备：本轮以 1440×900 桌面为主验收，补测 1366×768；未做手机布局。

## 方向选择

三个方向在 DSH 的同一套视觉令牌下只拉开骨架：

- **A · 一屏对话**：左栏 300px 同时装项目/会话与素材摘要；中间对话；右侧 380px 可折叠产物面板；完整素材库从左下角滑出 560px 抽屉。最接近参考，对话内容宽 680px。
- **B · 剪辑台**：236 / 288 / 1fr / 336 四区并置；素材常驻；四栏对宽度敏感。
- **C · 胶片带**：左 240 / 中 1fr / 右 320，素材是底部 98px 深色胶片带；最有辨识度，素材管理收起后较弱。

用户选定 **A**。理由：参考的安静感保留得最好；素材摘要仍常驻在左栏，完整管理走抽屉；右侧产物可收，聊天内容宽足够。代价是素材不是全程可见，抽屉打开时会遮挡聊天左侧。

### 文案与语义

- 「暂不采纳」不是取消后端草稿：草稿保留，可稍后回来确认；执行中另有「停止生成」。这是当前接口的真实边界。
- 「确认全部输出」后草稿只读；「正式导出需另行操作」。
- 产物中的任务标出版本（如 `V1 · 正式导出 · 1080p`），因为左侧草稿可能是 V2，而上一版 V1 的导出仍在进行；切换会话不会停止后台导出。
- 「播放 720p / 1080p」来自已完成记录；没有完成的成片时按钮显示「尚未导出」或「导出中…」。

## 动效

- **主操作反馈**：发送、确认、停止、上传按钮按下缩放；确认后右栏方案卡有一次短促的底色闪现。
- **状态切换来路**：右栏宽度过渡 280ms；素材抽屉从左侧滑入 300ms；方案从草稿变为已确认时，右栏在 44px 折叠和内容之间展开。
- **首次进入**：侧栏、对话、产物的透明度/位移动画，40–80ms 错开；只在页面首次加载时播放。
- 其他：上传/导出进度条、Thinking spinner、Toast 进出；`prefers-reduced-motion` 下全部缩短到 0.01ms。
- 草稿新卡只动 transform（不动 opacity），避免在重渲染时被动画卡成不可见。

## 自查与独立评审

两次派发给隔离评审执行者，均因执行超时未返回结论（没有留下评分）。因此本轮**没有独立评分**，只做了主 Agent 按同一手册的自查；不把自查冒充独立评审。

自查后修正的可见问题：

- 新草稿的入场动画原先只依赖 opacity，在重渲染时可能停在不可见；改为只动 transform，草稿不再有消失风险。
- 「回到最新」原依赖 scroll 事件和 follow 标志，在内容高度变化时不稳；改为生成完成时直接测量距底部距离，并关闭滚动锚定；已验证回看时出现、点击后回到底部。
- Toast 原在顶部会遮住当前消息；移到右下角，播放器打开时移到顶部，避免遮住播放器控件。
- 1366 下 4 段草稿的段名出现单字孤行；缩短段名，完整句子保留在助手消息与产物中。
- 素材抽屉与历史记录的小图标对比度偏低；提高到 ink-3，并放大历史按钮。

未做 / 已知差距：

- 没有独立评分；没有手机布局、真实媒体验证和后端联调。
- 渲染失败态没有在原型里模拟，只覆盖运行、停止、完成；真实失败需要接入任务状态后再做。
- 右侧「产物」数字只计当前方案、运行中任务和预览，不计导出历史；这是「当前产物」的口径，但可能与用户直觉有差异。
- 素材库没有缩略图，这是后端没有缩略图接口时的真实设计选择，不是遗漏。
