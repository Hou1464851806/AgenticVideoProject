# 可执行编排剪辑方案

本文件细化已确认的统一多输出方案。方案是业务数据；Agent 提出受约束的结构化内容，Spring 校验并分配业务标识，Java Worker 编译成 FFmpeg 执行计划。

## 版本与修改来源

- 方案版本不可原地覆盖。版本序号表示创建顺序，修改来源表示实际基准，两者不必相邻。
- 例如 V1 → V2 → V3 后选择 V1 修改，新建 V4，V4 的修改来源是 V1。
- 查看版本属于会话选择；Agent 执行基准属于任务固定输入。切换查看不会改变已经开始的修改、预览或导出。
- Agent 和手动编辑走同一个版本校验与追加入口；忙碌时同方案禁止再次修改。
- 一个方案版本包含全部输出定义，修改一条输出也形成完整新版本。确认绑定版本，不能自动继承到新版本。

## 最小结构示意

以下为结构示意，不对应真实素材；具体字段名在实现时可调整。

```json
{
  "schemaVersion": "1.0",
  "baseRevisionId": "revision-1",
  "outputs": [
    {
      "outputId": "output-a",
      "title": "第一个观点",
      "render": {
        "container": "mp4",
        "videoCodec": "h264",
        "audioCodec": "aac",
        "width": 1920,
        "height": 1080,
        "fit": "contain"
      },
      "clips": [
        {
          "clipId": "clip-a",
          "assetId": "asset-a",
          "sourceInMs": 120000,
          "sourceOutMs": 180000,
          "audio": "original"
        }
      ],
      "subtitles": {
        "enabled": true,
        "cues": [
          {"startMs": 0, "endMs": 2500, "text": "示例字幕"}
        ]
      }
    }
  ]
}
```

片段区间采用素材时间轴上的左闭右开范围，单位毫秒；音视频定位实际精度由源流、帧／采样边界和渲染实现验证。字幕时间属于该输出的成片时间轴，选段或重排后重新映射与校验。版本保存渲染所需字幕内容与时间，不在每次预览时重新调用 ASR。

多个输出表达拆短视频，同一输出内跨素材的有序片段表达混剪。首期硬切，无任意自定义转场脚本；画幅含 16:9 和 9:16，等比例缩放留边。渲染配置的默认帧率、字体与码率由执行端固定并记录配置版本。

## 确定性校验

保存新版本之前校验：

- 基准版本存在且属于当前方案；任务拥有当前编辑权，用户／项目归属来自后端上下文。
- 引用素材属于可访问项目，原始对象与探测信息有效；片段满足 0 ≤ in < out ≤ 素材时长。
- 输出及片段标识在范围内唯一，数量和总时长满足配置限制；时间计算无负数或溢出。
- 输出规格在支持列表内，字幕时间在对应成片时长内，文本与字体资源适合渲染。
- 片段顺序、原声音轨和字幕映射一致；无音轨素材由执行端按统一输出策略处理，例如补静音。
- 模型不能传入任意文件路径、下载地址、shell 命令或 FFmpeg 脚本作为方案。

结构化格式有效不等于语义符合用户要求；Agent 需说明选段依据，用户通过证据、片段播放和效果预览判断内容，再确认正式导出。

## 预览与正式渲染

两者使用相同版本内容与顺序，预览覆盖较低分辨率／码率配置；正式导出使用正式配置。预览无需正式确认，由用户手动请求；正式渲染需要确认记录和明确导出指令。

复用键包含版本、输出、实际预览配置和渲染规则版本，必要时还包括依赖素材／字幕资源指纹。已有有效产物或运行任务直接复用；缓存被清理后重新生成。清理记录同步标记产物不可用，不返回已删除文件链接。

渲染编译器与文件探测、进程执行各自封装，便于用确定性校验、短样本和实际导出验证。Worker 镜像需包含 FFmpeg、ffprobe、中文字体和字幕渲染所需支持；不能仅凭安装 FFmpeg 就假定中文字幕可用。
