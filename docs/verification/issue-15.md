# Issue #15：独立制作会话中的素材查询

2026-10-11。按用户确认的公开 HTTP、真实外部边界与浏览器闭环实施；对话模型采用用户指定的 `deepseek-flash`。

## 业务边界

会话属于已授权项目，创建时固定有效素材 ID 范围。查询无需创建剪辑方案；本次 ASSET／EVIDENCE 引用须属于该范围。可选 `context.assetIds` 只允许收窄，接纳时保存实际执行范围，不跟随页面后续选择改变。

接纳事务锁定会话，在同一 PostgreSQL 事务保存用户消息、轮次、AGENT_TURN 任务和 Outbox。相同幂等键与相同 JSON 内容返回原消息／轮次／任务；同键不同内容或活动轮次冲突拒绝。不同会话独立保存消息与运行上下文，界面保留各自草稿，任务执行时仍可输入。

任务通过持久 RabbitMQ 通知唤醒 Python，业务后端负责当前尝试、租约和结果发布资格。最终助手消息、验证后的证据引用、成功任务与执行回执同事务保存；重复发布返回既有回执，错误身份、迟到尝试及不同重复内容拒绝。失败任务不发布正式助手答复。

## 单 Agent 与证据

LangGraph 图包含模型节点、受控工具节点和终止分支；模型只能调用 list_assets、search_evidence、read_evidence_context 和提交答复的结构化函数。范围由 Spring 的固定任务输入注入，工具参数不能覆盖项目、用户或任务身份。当前检索为语音原文字面匹配；空检索词可有限浏览原句，无语义能力时明确说明。

每轮最多 6 次模型请求、12 次业务工具调用；候选最多 20 条，上下文最多 11 句。模型请求和成功回执私有持久保存，重放可复用已有响应；提交资格已使用而无成功回执时停止自动重复付费。实际供应商用量保留，不假造价格或费用。

模型工具消息和 reasoning_content 只用于私有协议。公开消息白名单保留正文、角色、顺序与经业务核对的出处；浏览器以文本渲染，引用定位原视频。业务历史存于 PostgreSQL，checkpoint 独立保存在 agent_state 卷的 /state，临时执行目录留在 agent_work 的 /work。

真实接口遵循 [DeepSeek 工具调用文档](https://api-docs.deepseek.com/guides/tool_calls/)、[思考模式协议](https://api-docs.deepseek.com/guides/thinking_mode/)及 [LangGraph Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api)。已配置账户的模型清单接口实际返回 deepseek-flash 与 deepseek-v4-pro，本票使用前者。

## 验证过程

- 会话入口最初 404；公开 HTTP 测试经真实 PostgreSQL 验证多会话、独立历史与跨用户 404。
- 接纳入口最初不存在；实现后验证重复请求、不同内容冲突、并发拒绝及不同会话独立接纳。
- 非法引用最初被接纳；实现校验后，非法输入不留下消息。
- Agent 任务最初不能领取；实现后验证当前尝试发布、重复回执和旧身份拒绝。
- 受控工具入口最初失败；实现后验证固定空范围、权限参数拒绝、调用幂等、12 次预算、6 次模型预算及提交资格不能重复使用。这些协议测试不作为真实模型能力的替代证明。
- 真实 DeepSeek 查询最初一直没有执行尝试；接通分发后从真实百炼语音证据正确回答讲述者“张明”，引用 ID、文本和素材经公开上下文接口核对。
- 会话 UI 最初缺少输入入口；实现后通过真实模型回答“三个制作步骤”，核查原视频，执行期间可编辑草稿。第二个会话不知道第一个会话的“海棠”代号。
- 两个真实浏览器标签页同时发送，只接纳一轮，另一轮冲突；重复发送仍返回原身份。
- 将已有会话范围收窄为空的测试最初仍读到“张明”；修复固定任务输入后，空范围诚实说明无语音证据，引用为空。
- 全量回归发现 checkpoint 占用了临时目录，影响旧 ASR 清理断言；将状态移到独立持久卷，校验复制成功后迁移旧文件，保留原清理断言。

- 需求审查发现同一签名 URL 连续核查不跳转；真实浏览器回归先失败，再为已就绪媒体直接应用新引用时间并同步定位秒数。
- 已知证据 ID 未经读取最初可直接发布；HTTP 回归先失败，再要求出处出现在本轮授权检索／上下文工具回执中。空引用的会话历史回答仍可发布。
- 全量套件新增真实对话后触发测试账号入口限流；同组对话测试改为内存复用真实登录 Cookie，每个独立页面仍核查素材可访问性，未提高生产认证限制。
