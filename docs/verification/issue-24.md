# #24 验证记录

## 交付范围

用户通过“生成低清效果预览”明确请求固定版本／输出，无需正式确认；预览独立于源片段播放和当前查看版本。接纳回执与渲染缓存分开持久化，同键重放保持原任务，显式失败重试创建新请求并保留历史。

Worker 在独立尝试目录检查剩余空间、下载并核对原素材、编译受控 FFmpeg 参数、顺序硬切、按显示比例留边、保留原声／补静音并烧录持久化字幕。最终视频完整解码、探测时长和音轨后上传当前尝试的服务端目标；业务端核对目标、对象大小、时长和规格后原子发布。取消确认要求进程退出；已终结尝试的未发布对象独立清理，删除失败保留待重试记录。

## 接口证据

`PreviewApiIntegrationTest` 通过公开用户 HTTP 和受保护执行器 HTTP 使用真实 PostgreSQL 与 Silo；测试准备先前已完成的版本及代表性探测回报，仅用于协议验证，不声称其测试上传字节是真实视频。

- 手动请求前没有预览任务；固定版本／输出，重复有效请求复用；他人版本、请求和产物不可访问。
- 当前尝试分配唯一上传目标；重复 claim／complete 复用；未上传产物不发布，完成后提供短期播放授权。
- 对象删除后授权返回 410，明确重新生成建立新请求／任务，保留旧成功记录。
- 失败显示原因；同键失败请求重放返回原接纳回执，同键异输入 409；新键显式重试保留失败请求。
- 运行中取消拒绝 processExited=false，退出后清理已上传但未发布对象。

## 真实媒体与故障证据

`frontend/e2e/previews.spec.ts` 从公开上传入口准备真实素材和已完成的 ASR；之前完成的方案版本由测试准备，避免把渲染验证误记为真实 Agent 生成验证（后者见 #20）。

- 真实带音频偏移的 labelled-speech 素材合成横屏 640×360、4 秒低清预览并在 Chromium 播放；探测 AAC 双声道／48kHz。实际抽帧确认中文正常显示。
- 真实 720×576、SAR16:15、无音轨红色视频与讲话素材合成竖屏 360×640；原显示比例为 4:3。像素检查验证留边和绿／红片段顺序，抽帧确认两段字幕按输出时间切换；后段音频能量验证补静音。
- 外部 HTTP 故障代理在服务器已接纳上传后的完成回报时丢弃首次响应；Worker 重报同一结果，保持一个尝试和一个产物。Rabbit 重投仍复用既有结果。执行期间追加版本并切换查看，不改变原请求的版本。
- 取消测试在外部进程边界放慢真实 FFmpeg 输入，等待本任务 RUNNING 和实际 FFmpeg 存在后取消；终态出现时进程已退出，未发布产物，没有增加尝试。
- 合成前后 ASR 调用记录不变。

## 审查与回归

相对 `b684a0c` 分别进行 Standards／Spec 审查。修复同项目复合外键、状态 CHECK、引用侧索引、请求幂等与不可变历史，以及非方形像素显示比例问题。真实 SAR 样本先失败（应为黑色留边的位置出现红色 252），修复后通过；渲染规则升级 v2，隔离旧缓存。README 与 API 说明同步。

Standards 与 Spec 均静态复核通过；保留一项非阻塞建议：将字幕／FFmpeg 参数编译从执行生命周期进一步分离。
