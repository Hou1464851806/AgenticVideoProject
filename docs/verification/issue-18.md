## TDD 与闭环

- 简报模式接纳400 → 工具保存条件、明确／默认来源及追加修订；纠正时长和禁用素材保留其他来源，工具回放不重复修订。
- WAITING_INPUT 完成409 → 发布有身份问题、释放当前尝试和方案占用；普通新消息409，不猜测回答。重放完成返回同一问题。
- 取消后仍等待 → 关闭问题、取消任务；晚到回答拒绝，新轮可开始。
- 新需求入口404；首实现来源外键顺序错误 → 原等待取消，任务先插入后建立新简报修订，重复请求复用接纳回执。
- 固定素材失效后回答拒绝，等待和消息保持不变；已有方案变化需明确新基准，新的恢复任务关联原等待。
- 应用简报生成接口400 → briefRevision 校验与条件冻结；问题卡无新基准控件 → 明确勾选当前查看版本后恢复。
- 禁用原文候选仍 valid=true → 业务确定性校验 valid=false；直接提交制作条件也校验禁用文本数组与长度。
