# Naive UI 第三阶段实施记录

2026-10-30（Asia/Shanghai）。状态：第三阶段完成；对应当前工作区未提交改动。未部署或调用真实付费模型。

## 实施

- 素材库使用 Naive UI Drawer；保留素材/查找标签和面板关联，提供方向键、Home、End 切换。组件库标签页未提供所需键盘语义，因此采用带语义的原生标签按钮。抽屉焦点循环在原片播放器打开时暂停，关闭后恢复到播放触发按钮。
- 素材行加入状态标签、操作弹出层与长文件名布局；打开更多操作不会触发画面分析，费用提示保留。
- 上传任务统一进度、状态和操作排版，保留原有上传模块与分片链路；进度提供可访问名称与数值。
- 对话中的素材引用可搜索、多选与移除，仅更新本轮素材引用；非素材引用保留，已选区域限高。
- 检索命中和补查观察按来源、时间、正文组织；邻近原文与观察帧可展开收起，显示候选数量和覆盖/费用提示。观察帧重新展开时重新获取访问地址。
