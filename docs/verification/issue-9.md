# Issue #9：上传后自动生成可定位的语音证据

2026-10-10，百炼北京区域真实联调。模型为 `qwen3-asr-flash-filetrans`，原生异步参数固定 `channel_id=[0]`、`enable_itn=false`、`enable_words=true`。

## 执行与三个信息层级

独立 Java Worker 验证源视频后提取 16 kHz 单声道 PCM 音频，保存校验值、提取规则与相对素材播放起点的时间偏移。独立 Python 服务从私有 Silo 有界读取并再次核对字节数及哈希，用官方临时上传将音频交给百炼；浏览器不连接模型服务。Spring 在媒体成功发布事务内创建分析版本、独立阶段、内容分析任务及 Outbox。

原始句／字词观察保存于 evidence_segments，检索单元及有序证据引用另存，原文提要以 EXTRACTIVE／NAVIGATION 标记独立保存。原始模型时间与映射后的素材时间同时保留，定位使用原视频时间。模型结果归档只保存必要 properties／transcripts，排除临时签名地址与凭据。分析版本固定源校验值及规则，模型调用保存参数、提供方任务 ID、请求 ID 和返回用量。

## 真实边界验证

- 无音轨视频测试先因阶段缺失失败；加入持久阶段后明确 ASR／INDEX 不适用，证据为空且可播放。媒体、语音与索引状态分别显示。
- 本地固定中文台词实际上传至百炼。首次下载被 HTTP 地址规则拒绝；按官方返回格式升级至 HTTPS 后，真实任务返回四个句段、字词时间戳和用量。接口轮询读取已记录任务，避免测试反复付费。
- 上传中文讲话视频后，最初 ASR 一直 PENDING；接入实际提取、模型调用和权威发布后通过自动流程。点击证据定位原视频，刷新后证据 ID 不变。
- 视频流起点为 0，音轨起点为 1436 ms。句段映射通过后，新增字词映射测试先因字段缺失失败，再补齐音频及素材时间并通过。
- 使用 Google FLEURS 的人工转写中文真实讲话样本，经视频容器、音频派生、百炼读取后，去掉标点的转写与人工文本一致；句段和字词存在且位于素材时长内。样本、来源、变换与 CC BY 4.0 署名见 fixtures/LICENSES.md。该单一样本不代表一般场景识别准确率。
- 提前打开播放器，最初不显示运行状态，也不会在完成后更新。服务端领取时更新 ASR RUNNING，页面查询阶段及证据后，已就绪结果可直接核查。
- 丢弃一次真实提供方查询响应，有限恢复后只查询原任务，恰好一次提交；三个实际 RabbitMQ 重复通知被消费，不增加尝试或再次提交。
- 在提供方任务 ID 已保存、查询响应在途时对 Python 服务发送 SIGKILL。服务端租约过期后先确认旧执行器尝试不存在，产生第二个尝试并查询同一提供方任务。只有一次付费提交、同一份证据，工作目录最终归零。
- 测试仅在内存捕获真实领取凭证；恢复完成后，用旧尝试提交完成和模型调用请求，两者均 409，证据 ID 保持不变。
- 暂时撤去凭据：原视频仍 VALID 且可播放，ASR 明确 UNVERIFIED，显示原因，没有虚构观察或模型调用记录。测试结束恢复原配置。
- 付费前的音频传递故障，最初被错误标为已提交而阻止恢复；拆为 LOOKUP／READY 与实际提交前 PREPARE／SUBMITTING 后，两次执行、一次真实 ASR 提交。
- 百炼实际接纳付费任务后丢弃提交回执。业务记录 UNCERTAIN，任务只执行一次，ASR 标记未验证，没有观察发布或自动重复提交。未取得任务 ID 时不能声称已查询或取消该提供方任务。

- 使用真实私有上传的损坏 WAV 触发百炼 `DECODE_ERROR`，最初被错误标为 UNVERIFIED。保存明确失败结果后，ASR／模型调用均为 FAILED，保留同一提供方任务 ID 和实际错误码；无观察发布、仅一次付费提交和一次执行。提供方未返回用量时不虚构为零。

## 运行记录

Python 为 `3.13.16`，镜像固定 digest，FastAPI `0.143.0`、requests `2.34.2`、pika `1.4.4`、boto3 `1.43.111` 及完整依赖锁已通过 arm64 构建。Python 服务单执行槽，私有工作卷，512 MiB／1 CPU，无宿主业务端口。小样本测得 Python 48.74 MiB、Java Worker 201.3 MiB；不是长视频或压力验证。

后端完整 Maven 验证 15 项通过（50 秒）；前端类型检查与生产构建通过；容器内真实模型测试通过。完整浏览器套件 26 项通过（6.6 分钟），包含本票九个语音分析场景及账号、项目、媒体和上传续传回归。故障注入结束后已恢复正常服务配置。

派生音频目前保存于私有 Silo，Python 执行目录在结束或重启时清理。派生音频的独立容量回收策略、历史素材补分析、主动阶段重试及索引重建仍由后续容量／恢复任务补齐；本票不将这些能力记为已验证。

接口依据：[Qwen ASR 原生异步与时间戳](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)、[临时私有上传](https://help.aliyun.com/zh/model-studio/get-temporary-file-url/)。临时模型文件按提供方时限失效；必要付费观察随素材保存，重建检索单元不重跑 ASR。
