# M2 阶段 1：跨语言契约与制作上下文

日期：2026-10-15（Asia/Shanghai）。依据系统临时目录中的 M2 交接文档及 [M2 最终设计](../java-tools-m2-design.md)，从 `31b272b` 开始实施。用户本轮明确授权阶段 1；原设计会话的暂缓实现限制已被本轮指令替代。原有 `AGENTS.md` 与 M2 设计文件内容未被覆盖。

## 交付范围

- Python `editing.py` 与 Java `EditDraftContracts` 定义草稿、逐输出规范化条件、结构化问题／校验结果、可信制作身份、保存请求／结果。模型提出的草稿不含字幕、总时长、业务标识或制作命令；工具参数移除 `read_ids/read_records`。
- 程序建立稳定 `output_key`，理解步骤仅提出条件增量；程序合并为逐输出条件。“第二条改为 20 秒”仅修改 `out-2`。默认一个输出、横屏、字幕开启、不要求完整字幕、无硬时长。默认来源与明确消息身份／原文随条件保存在 checkpoint 中，CLI/status 可查看；传给 Java 的规范化条件排除运行字段与来源元数据。
- V52 建立独立制作需求、固定项目／scope、原工具回执、校验与来源的关联。新方案版本可使用本需求的校验来源，旧任务来源继续保留并与新来源择一。同一需求唯一版本；保存结果含输出键映射，与方案版本同一行写入。此处验证的是数据库约束，没有实现保存事务接口。
- Mock 使用相同草稿／条件／校验数据形状；模拟校验读取可信 checkpoint 观察，不接受模型或客户端在校验参数中申报读取依据。Mock 执行器重建后不丢失合法读取，定向观察仍可被引用。Java 真校验对持久服务端读取回执的核验属于阶段 2。

## 验证边界与方法

用户确认的三个测试边界：Python/Java 解析与哈希、Python 条件合并入口、PostgreSQL 来源约束。使用公开 Agent 入口补充本次 Mock 契约调整引起的恢复／定向观察回归。新增行为先运行失败用例，再实现对应最小改动；完整回归留到收尾执行。

共享样例 `backend/src/test/resources/contracts/m2-editing.json` 被双方消费。测试覆盖中文、换行、emoji、U+001B 与字面 Unicode 转义、逐输出时长、不同输出排序、键唯一及一一对应、未知字段、空值、数值类型和 64 位溢出；输出 10／11、片段 100／101、Unicode 文本长度及 64KiB 请求／32KiB 结果边界。阶段 1 验证结构，不代替阶段 2 的素材时长、上下文完整读取、切词、字幕和禁词业务规则。

真实 PostgreSQL 18 Testcontainers 从空库应用全部 52 个 Flyway 迁移，检查跨项目 scope、跨制作需求校验、来源缺失、保存结果缺失和重复制作版本被约束拒绝；新来源不需要任务行，旧任务来源仍可写入。

## 审查与修正

按 code-review 技能分别执行 Standards 与 Spec 审查，固定点为实施前 HEAD `31b272b`，比较本次暂存及后续修正。

### Standards

发现 Mock 只保存执行器内读取状态，导致定向观察／重启来源丢失。新增两项公开入口回归，失败后修正：校验前从当前 checkpoint 的可信观察恢复 Mock 读取状态，并记录各成功读取／完成结果。仅对具体 Mock 适配，不扩展通用执行器协议。重复规范化条件转换被列为判断性建议；遵循最小修改原则，保留三个明确调用点。

### Spec

发现合法控制字符的 Unicode 转义大小写导致跨语言哈希不同。共享样例加入实际控制字符及字面转义，Java 哈希序列化采用与 Python 相同的小写十六进制转义，同时保留 UTF-8 emoji。Mock 来源问题与 Standards 重复，按同一修复处理。补充严格拒绝 Jackson 忽略的计算属性，避免其被当成合法输入字段。

Standards 初审 1 项回归、另 1 项判断性建议；Spec 初审 2 项问题（哈希与 Mock 来源）。两轴独立复核后均无剩余阻塞项，未发现越过阶段 1 的功能扩展。完整回归结果见下方。
