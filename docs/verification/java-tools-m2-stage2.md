# M2 阶段 2：Java 真实校验与规范化内容

日期：2026-10-15（Asia/Shanghai）。依据阶段 1 交接及 [M2 最终设计](../java-tools-m2-design.md)，从 `82e3771` 开始实施，工作区起始干净。用户明确授权阶段 2，并确认以此提交为审查基准，通过 Java HTTP 入口与真实 PostgreSQL 夹具测试；该边界不覆盖 Python 修正循环或实际渲染。

## 交付范围

- 内部认证客户端把独立制作需求绑定到固定项目／scope，随后调用 `validate_edit_draft`；模型参数不能替换制作身份。复用四读取工具的请求哈希、调用回执、依赖核验和重放机制。相同需求不能改绑，同 scope 的调用身份不能跨制作需求复用。
- 从固定 scope 的原始证据与服务端成功范围回执取依据，核验从首 cursor 到末页的完整链及范围覆盖；目录、检索与跳页不能代替完整读取。新分析 head 不改变校验和字幕依据。
- 对多输出逐片段核验素材／版本／引用、半开区间、同输出重叠、全部相交语音的词边界、无词时完整句、逐输出硬时长与明确原文禁词（按单个输出的实际入选转写匹配）。跨输出可复用；非法素材／区间不衍生误导性时长问题。
- 从原始 ASR 选取完整词并映射输出坐标，保留输入顺序和原区间，统一 720p／30fps／等比例留边规格。字幕关闭时 cues 为空，仍检查禁词和语音边界。音轨存在但没有转写时披露缺口；完整字幕依据 ASR 的处理覆盖及已识别语音判断，无音轨部分无需 ASR 字幕。没有新增语义裁判。
- 校验与工具结果同步提交；通过才保存规范化待保存内容，尚不分配业务 outputId/clipId。持久记录关联制作需求、项目、scope、调用身份、草稿／条件、哈希、来源和规则版本 `hardcut-m2-v1`。业务问题返回 READY + valid=false，身份／依赖问题停止；数据库与程序异常上抛。
- 工具反馈保留有界结构化问题，问题省略显式标记 `issues_truncated`，警告省略以 `WARNINGS_TRUNCATED` 披露。完整方案与字幕不重复塞入反馈。

## 模块边界

`ReadTools` 和 `QuestionToolController` 接纳固定路由并管理调用；`EditDraftValidation` 管理剪辑规则和规范化内容；`DraftEvidence` 读取固定证据和持久分页依据；`ProductionDrafts` 管理制作绑定及校验事务。语音选词与安全边界集中在已有 `SpeechTimings`，旧方案入口复用，不复制另一套词规则。沿用 V52 表结构，没有新数据库迁移、消息链路或通用工具框架。

## 验证与审查

专项包含合法多素材多输出、实际读取与漏页、错版本、新 head、切词、缺词时间、越界、重叠、硬时长、视觉点、字幕开关／缺口／完整性、画幅、身份／哈希／重放、反馈截断与数据库故障。

实施中的红→绿用例揭示并修正：音轨提前于源零点时，不能从已裁剪语句反推偏移；候选词边界需要同时避开其他原句；音轨实际开始前的时间不应要求 ASR 覆盖；禁用原文跨 ASR 句子拆分时仍应匹配。新增数据库故障注入检查事务与未核对回执，并修复既有安全链把服务器错误分派改成 401 的问题，使原 HTTP 500 保留且异常仍上抛。缺少制作所需固定音轨信息的旧 scope 明确停止，不以缺字段推断无音轨，也不自动刷新快照。反馈上限的初审发现及修正见下方双轴审查。

### Standards

初审与修正复核均无发现。规则、证据读取与制作持久化的职责边界符合仓库规范；共享语音规则避免重复实现，未增加推测性功能、吞错或不必要回退。

### Spec

初审确认 1 项缺陷：原裁剪逻辑先删除警告，再加入 `WARNINGS_TRUNCATED`，标记可能使合法结果重新超出 32KiB。用 10 输出×20 个合法视觉片段、不同长度调用身份通过公开 HTTP 复现失败；修正为先把标记纳入预算再删除普通警告。修正后的 17 项新增专项全部通过。收尾复核再发现跨片段禁词绕过：同一输出中，把禁用原文拆成两个合法片段仍应拒绝。公开 HTTP 先验证失败，再补按输出顺序的实际转写匹配，保留片段内定位且避免重复；独立输出不相拼，无效区间或非法选词不衍生跨片段问题。最终 18 项专项全部通过，两次修正均经独立复核。

审查另提出“ASR 处理完整但没有转写是否仍能满足完整字幕”的疑问。依据设计的明确限定：“程序检查基于 ASR 处理覆盖和已识别语音；不要求静音每一毫秒都有文字，也不承诺 ASR 没有漏识别”，审查代理复核后撤回该项。保留通过行为，并增加公开 HTTP 测试与明确警告，不能把这一通过解释为无潜在漏识别。

两轴收尾：Standards 0 项；Spec 2 项已修复，0 项剩余阻塞。
