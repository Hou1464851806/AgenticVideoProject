# #20 验证记录

## 交付范围

一份讲话素材、一条输出的初始编排方案；主题、硬时长与画幅在接纳时固定。新方案／版本／片段／输出标识由业务后端分配。独占编辑与有效任务尝试绑定，历史版本和查看偏好独立。Agent 私有候选与自检不产生业务版本，最多校验三份不同候选；仅持久校验通过的候选可提交。版本保留原声、源毫秒半开区间、字幕文字与输出时间，复用原有 ASR。

## 接口证据

`EditPlanApiIntegrationTest` 经公开 HTTP 和受保护执行器 HTTP 使用真实 PostgreSQL；仅预先完成的 ASR 数据由测试准备，不把它作为真实模型验证。

- 多份方案、重复接纳、他人项目／方案不可访问，候选没有版本。
- 成功完整快照及原文字幕映射、首次唯一版本、重复完成复用，结果类型改变拒绝。
- 越界、重叠、硬时长不足均拒绝，三份候选后停止修正；未经持久校验不得直接提交。
- 时长大整数溢出拒绝，接纳失败不留消息或方案。
- 活动编辑独占；待执行取消、故障释放；运行中取消保持占用直到当前执行器确认退出，拒绝迟到结果。
- 任意历史基准在接纳后不变；任务完成不改变查看版本。
- 同一 ASR 段包含独立观点时按真实词级边界选段并映射原文字幕，词中截断拒绝。

## 真实模型与浏览器证据

`frontend/e2e/conversations.spec.ts` 的 human-transcribed viewpoint 用真实 FLEURS 中文讲话样本（CC-BY 4.0，出处见 fixtures/LICENSES.md），上传后调用北京百炼 ASR，再由 deepseek-flash 核查并提出方案。

人工参考：“这并不是告别。这是一个篇章的结束，也是新篇章的开始。”要求 7–11 秒、不重复／变速，可保留源片前后停顿。验证方案字幕覆盖完整人工文本、源范围与硬时长；真实界面选择版本、显示文件名／依据、按源片终点停止；再通过界面新建方案后仍保持原查看版本。同一源素材两次生成前后 ASR 调用和观察完全相同。11 秒源视频要求 12–13 秒且禁止重复／变速时，真实 Agent 解释并不创建版本。切换空项目检查不展示旧方案。
