# #13 在预算内复查候选，超预算先询问

固定审查基线 `85e03bc62c206cc3c3510a62569c729e49e753ad`。测试继续使用已确认的公开 HTTP、真实 PostgreSQL / Silo / 媒体 / 百炼及 Compose 浏览器边界。

## 实现与实际验证

- 独立 `visual-inspections` 接口及证据检索结果卡支持候选附近加密采样，或没有候选时对指定素材做预算内覆盖采样。不依赖制作会话。使用原始解码 PTS，保留来源、帧身份、模型调用身份与观察时刻。
- 首轮预算由程序固定为 4 帧、4 次新视觉调用、8 个步骤、180 秒和 4 MiB 模型图片输入。步骤包括执行器领取、付费调用授权和发布。计数及共同截止时间持久化；重复领取、恢复执行和模型请求不能重置预算。执行器检查截止时间，服务端心跳要求停止，当前尝试／版本校验阻止晚到发布。未知付费结果不自动重复提交。
- 完成一轮或没有新匹配后停止。扩大方案先持久化拟扩大素材／范围、新增预算和费用估算；此时没有子任务。所有者明确接受后创建独立的 8 帧、8 次调用、16 步、300 秒、8 MiB 子轮次，原轮预算与结果保留。拒绝不创建子任务；重复选择幂等，不允许把已有拒绝改成接受。
- 北京 `qwen3-vl-plus` 的费用说明按 [百炼官方价格](https://help.aliyun.com/zh/model-studio/model-pricing) 提供保守 token 估算，8 次约人民币 0.36 元，实际账单仍以提供方用量和价格为准。程序硬限制调用、帧、步骤、时间和图片字节，不将估算描述为金额保证。
- 新帧与新证据追加保存，不更改历史帧、观察或原稀疏采样记录。已成功的相同图像调用可复用；新增观察参与完整检索代次。结果明确说明加密采样仍会遗漏短暂文字、小字及其他画面。

## 人工标注样本与 TDD

`brief-small-text.mp4` 是 4 秒、20 fps、无音轨的白底红矩形视频，16 像素“瞬时83”只在 900–1350 ms 的帧可见，没有飞机。独立 ffprobe 核对 20/1 与 4.000000 秒，人工查看原绘图确认小字；标签在模型调用前确定。0 / 2000 ms 稀疏采样不包含文字；500–1500 ms 加密采样实际得到 500、750、1000、1250 ms。真实 VLM 在最后两帧识别文字，4 帧只产生 2 个唯一图像调用。

1. 独立补查入口 404 → 真实媒体／VLM 的短暂小字补查通过，首轮观察未覆盖。
2. 缺少浏览器入口 → 无候选覆盖补查结果卡通过，负例“未出现的飞机”返回有限停止及覆盖警告。
3. 缺少扩大选择 → 拒绝保留已有观察，接受创建独立预算轮次，两条浏览器流程通过。
4. 已过期预算心跳 CONTINUE → STOP，结果 BUDGET_EXHAUSTED；取消确认不覆盖预算耗尽原因。
5. 分析 head 失效仍可 LOOKUP → 409，不能继续获得付费资格。
6. 调用／步骤／输入预算耗尽拒绝新增提交；恶意 resetBudget / maxCalls 参数不能改变预算。超限 5 帧原子拒绝，取消后晚到结果拒绝。
7. 选择发生在方案生成前原先 500 → 409；所有者校验、选择及完成回报幂等通过。

8. 审查发现范围外 callId 可获付费资格 → 409 且计数不变；候选补查沿用证据来源，不受后来切换筛选项影响。

单文件后端 9/9 及完整 Maven verify 已通过，72 项测试、0 失败／错误，BUILD SUCCESS（5:10）。前端 vue-tsc / Vite 和完整三服务镜像构建通过。完整浏览器回归执行了 59 条，包括 3 条真实补查及候选来源回归：58 条通过；既有会话隔离用例的一次真实 DeepSeek 调用回执 UNCERTAIN，系统按设计停止自动重提。随后用新会话独立复验该用例，1/1 通过（11.8 秒）。全部用例均取得通过结果，但不是单次全量运行 59/59；未知回执的原调用没有自动重放。完整回归耗时 17.3 分钟。

全量回归发现既有语音恢复测试把工作卷根目录的无关文件误当本次残留；已改为核对本次领取的两个 attempt 目录，保留其他文件。故障恢复、ASR 唯一提交、旧尝试拒绝和证据不变的原断言保留。
