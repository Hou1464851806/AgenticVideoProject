# 实施顺序与验收

Q58 及 2026-10-12 统一自然语言共识已确认，本文件为实施与验收基线。详细规格见 database-design.md、api-contract.md、event-protocol.md，任务依赖与完成标准见 development-backlog.md；已实现与验证进度见 implementation-status.md，新增统一对话流程待实施。

## 当前优先交付：单条完整对话流程

依据 [统一自然语言设计](natural-language-workflow-design.md)，先在已完成基础能力上推进两个阶段：

1. 自动会话与统一消息入口；意图、对象、条件与默认值；需求隔离和同输入框澄清；理解后接纳固定执行请求；接入已有查询、生成、预览、确认和导出能力。
2. 补齐指定片段修改、项目自动补查授权与需求累计额度、用户明确要求的连续步骤，验收单条讲话视频与单条跨素材混剪的完整对话流程。

不选择需求类型、证据类型或检索方式，不填写制作／澄清表单、不手动应用简报，通过聊天完成查找、生成、指定片段修改、预览、确认和导出，才算该里程碑完成。采用 requirements.md 的 AC-NL-01 至 AC-NL-12；验证证据、硬条件、局部修改范围、实际可播放 MP4、权限、预算及重试一致性。

多条生成 #21、批量导出 #26 和原 MVP 其他任务随后继续，最终范围不变。以下阶段表保留原完整 MVP 路线；近期增量任务 NL1–NL5 见 development-backlog.md，不把旧票完成或按钮可点击当作统一对话验收通过。

## 实施顺序

| 阶段 | 交付范围 | 完成标准 |
| --- | --- | --- |
| 1. 最小基础闭环 | Compose、用户与项目、Silo 分片直传与续传、限额／空间预留、完整媒体验证、播放、任务与 Outbox | 上传可恢复，重复完成不重复入库；无效媒体和越权操作被拒绝 |
| 2. 理解与检索 | 固定分析与时间映射、分来源证据、百炼 ASR、基础 VLM、Qwen 稠密向量＋Qdrant 中文 BM25／RRF、阶段就绪与索引发布、用量统计 | 已知文字／场景能返回可核查出处与观察时间，分析与索引故障不导致盲目重复模型调用 |
| 3. 讲话视频拆短视频 | 持久多轮对话与 SSE 恢复、三区工作区、DeepSeek＋LangGraph、有界上下文、方案历史／互斥编辑、片段调整、明确请求预览、确认与多输出导出 | 对话和页面刷新恢复正确，完成第一条真实剪辑闭环，旧版本仍可预览／导出 |
| 4. 基础混剪 | 跨素材选段与顺序编排、画面适配、音轨统一、字幕时间映射 | 多素材混剪成一段可播放视频，内容顺序和音画符合方案 |
| 5. 完整 MVP 验收 | 缓存清理、恢复／取消、隔离、用量展示、部署说明 | 功能与故障场景通过；在本机记录性能和资源占用 |

重试、鉴权、任务状态与结果校验从第一阶段融入，最后阶段验证其完整性，不等到功能完成后才补基础协议。

## 功能验收

1. 中文讲话长视频：要求多个观点完整的片段，Agent 给出处与切点；可对话修改、手动调整、切换历史，预览后确认并分别导出。
2. 多视频混剪：从多个素材选择指定主题内容，按要求排序，保留原声与字幕；生成横屏或竖屏的单条视频。
3. 内容查询：已知语音短语、画面或可见文字查询，返回素材、时间范围与证据，能跳转播放；无证据时说明无法确定。

使用小型、内容可核对的素材作为固定验收样本，人工标注目标内容和合理切点。样本不以默认模型生成结果作为正确答案；粗视觉分析与细致复查分别检验。

## 上传与多轮对话验收

Q49–Q57 已确认设计见 upload-design.md 与 conversation-design.md：

- 分片直传实际 CORS／ETag、授权过期、断网逐片重试、暂停／恢复、刷新重选同文件；同名不同内容不能续接，双标签页不竞争写入。
- multipart 创建／完成响应丢失、重复完成、取消与完成竞争、在途分片与过期残留；恢复后只发布一份验证通过的素材，容量在实际核对后释放。
- 单文件 2 GiB／项目 5 GiB／未完成 24 小时限制可配置，低空间和并发预留正确；字节数、文件哈希、不可解码视频和超时长校验有效。
- 重复消息 POST 返回同一轮次／任务；同会话并发发送被拒绝，不同会话与同方案编辑锁分别处理。
- 发送后刷新、断线重连、事件重复和游标过期不丢关键结果；旧尝试草稿不拼接新回复，后台继续执行且显式取消有效。
- 澄清回答关联原问题，开始新需求结束等待；失败重试不重复用户消息或已提交版本，已成功但通知丢失时读取既有结果。
- 发送时固定素材／版本／输出，查看切换不改执行基准；证据卡跳转正确，Agent 修改时保留既有手动编辑限制。
- 长历史摘要不丢精确约束，需求简报可通过自然语言纠正；供应商内部推理、工具凭证与私有路径不进入公开聊天。

## 视频理解与检索验收

Q42–Q47 已确认设计见 video-understanding-retrieval.md。实施第二阶段先验证一段中文讲话与屏幕文字样本的真实云模型读取、时间映射、分来源证据、向量维度、中文 BM25 分词一致性与 RRF，再扩展固定样本：

- 对比语义单路、BM25 单路与融合的召回率和排序；保留未参与调参的查询，必要时再评估精排。
- 语音提及但画面未出现、画面出现但无语音、精确人名／数字／短语与短暂文字，检查来源和覆盖说明。
- 音画起点偏移、可变帧率、无音轨、重复帧不同时间出现，检查播放定位与上下文完整性。
- ASR 已就绪而视觉失败／未完成时语音可用；索引失败重建不重跑成功的 ASR／VLM。
- 新代次发布前不进入召回，旧尝试／取消任务结果不能成为有效索引；各通道在召回前限定项目与有效代次。
- 未命中、部分分析和超预算深入检索的反馈准确，不虚构内容不存在或识别绝无遗漏。

记录 Recall@K、排序质量、时间定位误差、句意完整性、查询延迟、每小时分析调用量与费用；具体阈值以代表样本建立基线。

## 状态与故障验收

- 基于旧版本修改追加新版本，来源正确；切换历史不新增版本，也不改变正在执行任务的输入。
- Agent 忙碌时手动编辑和第二次修改被拒绝，查看历史仍可用；失败／取消／重启后编辑权可恢复。
- 已确认旧版保留确认；新版本未确认不能正式导出；批量导出显示每条输出状态和部分失败。
- 手动预览重复点击、消息重投递、结果重复回报不会重复发布产物；过期预览可重新生成。
- 在数据库提交后、消息确认前、产物上传后或回报前中断，检查任务、产物及 Outbox 的恢复。
- 任务取消与完成竞争、租约过期后的旧尝试回报被正确处理；本地 FFmpeg 确认退出，临时目录可回收。
- 异步模型任务超时后查询已有任务，不盲目重做；无法确认的外部执行记录不确定状态与可能费用。
- Agent 澄清进入 WAITING_INPUT 后不占用执行槽或方案编辑权，重启不盲目重跑；回答后正确核对基准，checkpoint 重执行不重复产生版本或重复发布问题。

## Agent 智能验收

已确认有限自主单 Agent、关键条件澄清、预算内补查与证据编排目标，以及分阶段工作流＋按需轻量规划＋阶段内受限 ReAct，详见 agent-design.md。用固定素材检验多轮检索、候选复查、观点完整性、局部修改范围、硬条件遵守和无证据时的诚实失败；简单请求不强制完整长计划，复杂请求的策略应有据调整。任务策略与内部草稿迭代不能不断追加业务版本；测试预算耗尽、无新证据和校验修正上限时的收束。

## 权限与文件保留验收

- 两个账号不能读取彼此项目、检索证据、对象链接或任务；内部服务鉴权不依赖模型自报用户标识。
- 隐藏被引用素材后历史版本仍可渲染；直接彻底删除被引用素材被阻止。
- 预览按 2 GB／7 天策略测试清理，配置可修改；正在使用文件跳过，正式成片和原始素材不受预览清理影响。
- 分析证据及历史引用保留；清理派生音频／普通代表帧后可按源素材与规则重建，佐证帧可访问或可靠复现，重建媒体不重复调用模型。
- 预签名上传／下载受项目权限、对象与操作范围约束；在 Silo 上验证真实兼容行为和 Range 播放。

## 成本与本机测量

统计模型提供方、模型、调用用途、实际用量、估算费用及重试；没有提供方用量时明确标记估算。方案重排、重新预览与渲染复用已有分析。

记录转写、视觉分析、检索、方案生成、预览和正式渲染分别耗时，记录 Docker 内存、CPU、工作磁盘峰值及缓存大小。由真实样本固定抽帧、分辨率、码率、超时和调用上限，初期不承诺未经测量的吞吐或费用。

## 实施时需核验固定的参数

- JDK／Spring Boot、Python／FastAPI／LangGraph、Vue 和基础设施镜像版本及 arm64 支持。
- 百炼地域、ASR 任务接口与时间戳、VLM 图像参数、Embedding 模型与维度，以及 DeepSeek 工具调用／结构化输出契约。
- Qdrant 固定版本候选 v1.19.2 的实际部署、中文 BM25 索引／查询一致性、项目 IDF 范围与 RRF；召回量、文本窗口、采样量通过评测固定。
- 本机派生音频／帧传给云模型的实际接口路径、提供方任务恢复、费用；更换模型后的增量分析／索引重建。
- FFmpeg 构建、编解码器、中文字幕字体、字幕滤镜，以及镜像内实际音画导出。
- RabbitMQ ack 时机与长任务恢复、SSE 重连、心跳／租约、模型请求与本地进程的超时。
- 固定 Silo 版本的 multipart／预签名 PUT／列片分页／完成错误与取消清理，实际浏览器可达地址和 CORS；有界增量哈希、分片尺寸与共享并发池。
- 同源登录、SSE 代理缓冲／超时、公开事件提交序列／重放／快照边界、历史分页、模型上下文与摘要阈值。
- 数据库和对象存储持久卷、工作目录容量与派生文件清理。

这些属于实施核验和配置参数，不改变已确认的产品边界；若实测出现影响首期需求的能力缺口，更新设计并说明权衡。
