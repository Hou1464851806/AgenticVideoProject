2026-10-13 已实现 #23：在方案中引用版本、成片或片段，再说“替换第二段”或“更紧凑但保留第二段结论”。修改保留原硬条件和未指定的内容，结果附实际变更说明；基于旧版修改追加到历史末尾，完成提示保持当前查看版。指代不明先澄清，同一方案跨会话只允许一个有效编辑。

版本按明确引用、发送时查看版、本会话最近生成版依次确定。确认不随新版本传递；普通评价、素材里的指令文字和“做完就导出”不构成导出授权。混剪的可用素材范围与必须参与的素材分别保存，字幕来自原语音，无音轨片段保持静音。以下具名模式入口继续可用。

## 账号与私有项目

- 注册、登录、退出；账号和项目在服务重启后保留。
- 创建、打开多个私有项目；素材、对话、方案、任务和产物按账号及项目隔离。
- 素材、对话、播放器与结果区域可在窄屏中切换。

## 视频上传与原素材核查

- 多视频直接分片上传到对象存储；区分传输完成与媒体验证完成。
- 暂停、继续、断网重试；刷新后重选原文件，校验文件身份，只补传缺失分片。
- 取消未完成上传并停止后续调度；素材名额先释放，残留清理及字节占用释放单独显示，清理失败自动重试。
- 未完成上传默认最后合法活动后 24 小时过期，可配置；显示恢复期限，过期后要求重新上传。读取状态不续期，合法完成中的操作受到保护。
- 默认单文件 2 GiB、每项目 10 个视频及 5 GiB 原始素材，可配置；并发上传原子预留，超额明确提示限制及可行操作。
- 实测 Docker 对象和工作区卷空间，为上传、派生媒体、排队预览及导出预留未来写入；执行前再次检查，低空间拒绝开始并提示清理或扩容。
- 服务器检查大小、SHA-256、视频格式和实际解码；不合格文件展示原因，并在确认清理后更新状态。
- 素材库查看文件及验证状态，鉴权播放原视频，按指定时间核查原内容。

## 语音证据与检索

- 有音轨的视频上传验证后自动进行真实百炼语音识别，保存原文及对应原素材时间。
- 无音轨、分析中、失败和未验证状态分别显示，不把缺少分析当作没有内容。
- 查找人名、数字、原句；查看匹配原文及邻近上下文，跳转原视频核查。
- 展示已分析素材及时间覆盖，语音与索引状态分别显示；可单独重建检索索引。
- 可选择主题与近义表达检索，使用真实 Qwen 文本向量、中文 BM25 与原文通道融合；结果保留原始证据引用。
- 制作会话的检索工具共享同一项目及固定素材范围。主题结果是待核查候选，相关性排名不代表事实置信度。

## 画面与可见文字证据

- 在素材库点击“分析画面”，通过真实百炼视觉模型识别稀疏代表帧；画面、可见文字和语音提及分开。
- 检索选择“画面”或“可见文字”，支持原文与主题召回；查看佐证帧，按实际观察时刻跳转原视频。
- 重复图像保留各次出现时刻并复用成功调用；视觉和索引状态独立，视觉失败不阻塞语音。
- 单帧证据表示观察时刻，未观察区间不表示持续出现；稀疏采样和识别可能遗漏，未命中不证明不存在。

## 预算内复查与扩大选择

- 在候选附近加密采样；没有候选时对指定素材做有限覆盖补查，追加带来源和时间的新观察。
- 首轮限制 4 帧、4 次新视觉调用、8 步、180 秒和 4 MiB 图片输入；恢复与重复请求不能重置预算。
- 扩大前展示素材、时间范围、预算和费用估算，明确接受才启动独立子轮次；拒绝保留已有结果。
- 结果卡说明观察覆盖及可能遗漏；当前由用户操作发起，尚未接入 Agent 自主工具。

## 分阶段恢复与索引配置

- 不依赖播放的素材状态入口，分别显示媒体、语音、画面、Embedding、索引状态；只恢复失败阶段，避免误报全部就绪。
- 临时媒体执行失败或取消可保留原文件恢复；确定无效或已进入清理的文件解释原因并要求重新上传。
- 视觉失败不影响已有语音查询；已知 ASR 任务恢复原提供方任务，明确失败后由用户重试才创建新调用并保留旧回执，未知结果不重复提交。
- 索引失败复用持久证据和成功向量；只修改 BM25 配置不重复 Embedding，模型或维度变化使用独立索引。
- 重建期间使用旧有效代次，核对成功后才发布；取消、过期或迟到结果不能切换映射。

## 独立制作会话

- 创建不同制作会话，固定各自素材范围；保存用户需求、助手答复及证据引用。
- 使用 `deepseek-flash` 对话查询语音、画面和可见文字证据；答复引用可跳转核查原素材。
- 会话之间保留独立上下文；处理上一轮时可以继续编辑草稿。
- 刷新或断线后恢复消息、当前执行阶段及未完成草稿；关闭页面不会停止后台任务。每个项目共用一个鉴权事件流，游标过期时重新读取一致快照。
- 未完成草稿按执行尝试分开，明确标注尚未正式发布；恢复窗口最多 10 份，较早草稿可以分页读取。登录失效时关闭订阅并返回登录入口。

- 明确停止当前对话，撤销本地发布资格并释放执行占用；已正式成功的结果不会被迟到停止改写。
- 失败后关联原需求重试，保留原消息与旧失败，重新验证素材和方案占用；重复请求复用已接纳任务或成功结果。
- 同步模型与查询向量调用的未知费用明确展示；用户确认可能产生新费用后才允许重试，远端计算和收费不保证撤销。

## 一条讲话短视频方案

- 在“生成讲话方案”中填写主题、硬时长范围、横屏或竖屏，再发送制作需求。
- 从一份讲话素材生成一条方案，包含源片段区间、选取依据、原声与映射后的原文字幕。
- 核查和播放每个源片段；查看不可变历史版本，选择已有版本作为继续生成的基准。
- 同一方案的编辑任务有独占控制，可停止方案修改；切换查看版本不改变已接纳任务的固定输入。
- 无法满足硬条件时解释原因，不提交不合格版本。

## 低清效果预览

- 手动生成当前版本的 360p 低清效果预览，包含原声与中文字幕。
- 根据方案横竖屏比例合成；片段硬切，保持源素材显示比例，无音轨片段补静音。
- 播放、停止预览；重复请求复用有效任务或产物。
- 预览与正式确认、导出分开，生成方案不会自动渲染。

## 确认、正式导出与历史成片

- 明确确认某个不可变版本，再另行发起正式导出；新版本不继承旧版本确认。
- 每次选择一条成片定义，导出横屏或竖屏的 720p／1080p MP4（H.264 视频、AAC 音频）。默认同时执行一项媒体任务。
- 播放、下载成片；下载保留文件。明确删除成片文件，核对实际释放字节；删除故障会保留请求并重试。
- 刷新后查看导出历史、选择此前成功成片，再次播放、下载或删除；后续失败和取消不移除已有成功成片或原素材。
- 制作会话可明确发送“确认当前版本”，再另行发送“导出当前版本 720p”或“导出当前版本 1080p”；也可指定 V1 等版本。问句、否定或歧义先澄清；助手自身规划不能代替用户授权。
- 从对话回执点击“查看正式导出”，进入对应的固定版本任务与产物。

## 推荐体验顺序

注册／登录 → 创建项目 → 上传讲话视频 → 等待验证和语音分析 → 查找原文／对话核查 → 填写主题与时长生成方案 → 核查源片段 → 手动低清预览 → 确认版本 → 720p／1080p 正式导出 → 播放／下载。

## 分类存储与模型用量

- 项目中点击“查看存储与模型用量”，核对原始素材、派生媒体、低清预览、正式成片的真实占用、未完成预留和待清理占用。预留包含执行工作区预算。
- 查看语音、画面、Agent、索引向量和查询向量的提供方、模型、用途、回执状态、实际用量或明确估算、公开价估算费用。缺价格单列未知，未知回执不冒充免费。
- 配置项目累计费用、调用次数、token、音频秒数的预警阈值；留空关闭，只提示、不阻止任务。
- 缓存向量批次、已有分析及预览产物可复用；同一次检索的相同模型／维度共用查询向量。费用不是提供方实际账单。

## 按指定顺序跨素材混剪

- 在需求类型选择“生成跨素材混剪”，勾选至少两份素材，用上移／下移明确顺序，填写主题、硬时长与横竖屏。
- Agent 核查每份素材的语音、画面或可见文字及邻近上下文，按指定顺序生成同一方案的一条成片定义；同素材片段不重叠，不跨项目或固定范围。
- 原文字幕按各片段映射到成片时间；无音轨素材保留静音，不编造字幕。画面帧只证明观察时刻，源片段仍需回看核查。
- 沿用版本历史、编辑互斥、确认、低清预览及明确导出；可核查各源片段、播放并下载实际混剪 MP4。不同尺寸／采样率统一，横竖屏保持比例留边。
- 顺序、证据或时长无法满足时解释，不发布假版本；渲染复用既有分析，不新增模型调用。

## 制作需求简报与澄清（#18）

- 在“整理制作需求”模式中用自然语言说明或纠正主题、数量、硬时长、素材范围、禁用内容／素材与画幅。简报显示明确约束、已说明默认值、来源消息和修订历史。
- 关键条件缺失时显示独立问题卡；在卡片中回答才能继续原需求。等待时可刷新或重启服务，不自动重新调用模型，方案编辑占用已释放。
- 可停止等待，或在对话输入填写新需求后选择“开始新需求”。继续时重验素材；方案变化时可显式使用当前查看版本，形成关联新任务。
- 检查简报后点击“应用简报生成讲话方案”或“应用简报生成混剪”，再发送需求。接纳时固定简报版本；版本变化须重新应用。当前每次只支持一份方案，数量大于一会明确拒绝。
- 禁用素材从生成范围排除，明确禁用原文由业务校验拒绝；画面与语义禁用条件仍依赖所获取证据和模型核查，稀疏观察不能证明未观察片段完全无该内容。
