## 模块与目录基线

建议首次代码骨架使用以下边界，具体 build 文件与依赖版本在任务 G0 核验后生成：

```text
backend/
  business-api/       Spring 业务入口与权威持久状态
  media-worker/       独立非Web执行端与FFmpeg进程管理
  protocol/           Java共享任务DTO与Schema版本
agent-service/       FastAPI、LangGraph、模型适配、固定分析与检索
frontend/            Vue 3、TypeScript工作区与恢复状态
contracts/           HTTP/结果/事件Schema，Python和TS从契约校准
infra/               Compose、配置示例、镜像与持久卷说明
docs/                设计、ADR、验收记录
```

business-api 内按 identity、project、upload、asset、analysis、conversation、plan、task、render、usage 分模块，不为每个模块拆独立服务。Python 内将模型适配、固定分析、检索、编辑图与运行回报分模块，不默认新增独立模型网关。共享契约不等于 Java 模型直接作为 Python 内部状态。

## 验证范围

为涉及并发、恢复、权限、媒体正确性和外部契约的实现写有价值的测试；文档、样式及无行为的低影响改动不机械补测试。服务单测验证业务约束，PG／Silo／Rabbit集成验证真实边界，小型人工标注素材验证模型／Agent能力。通过既定范围后，不无理由重复扩大测试。

先交付“上传可恢复＋内容可查询＋讲话视频可导出”的最小真实闭环，再扩大到混剪和完整故障验收。功能任务依赖是工作顺序，未要求额外创建新聊天、自动化或Git提交。
