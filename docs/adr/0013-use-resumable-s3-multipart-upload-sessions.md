# 上传采用可恢复的 S3 multipart 会话与完整验证

浏览器通过短期分片授权直传 Silo，Spring Boot 持久管理上传身份、权限、清单、空间预留与完成／取消，复用对象存储的 multipart，避免业务 API 搬运整文件或增加独立续传服务。暂停与刷新恢复保留成功片，重选原文件后校验内容；只有对象完整性与媒体探测通过才发布可用素材，代价是需协调对象存储与数据库恢复、浏览器文件重选、分片残留和取消竞争。首期单文件 2 GiB、项目原始素材 5 GiB、未完成上传最后活动后 24 小时过期均可配置，实际空间及 Silo 兼容性仍需验证。
