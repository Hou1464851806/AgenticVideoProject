# 统一自然语言入口并在理解后接纳执行请求

2026-10-12 确认：用户通过一个聊天入口表达视频工作目标，现有单 Agent 理解意图、对象与条件，业务后端校验并保存固定执行请求后再分配方案、取得编辑占用；检索、分析、编辑和渲染复用既有执行模块。相较让前端选择模式并预填参数，此决定把理解规则集中在对话模块；相较拆分分类服务或多个 Agent，它减少重复判断与部署协作，同时保留程序对权限、版本和预算的控制。代价是需要把既有接纳顺序拆为消息接纳与解析后的执行接纳，并持久关联解析结果、问题、执行请求和需求累计额度；重试不得改写已接纳输入。首个交付里程碑以单条讲话视频或跨素材混剪的完整对话流程验收，预览仍须用户明确请求，具体版本确认与明确导出授权继续有效；详见 [统一自然语言设计](../natural-language-workflow-design.md)，本决定补充 ADR-0009／0014，不代表功能已实施。
