# 保留方案历史并避免 Agent 与用户同时编辑

产品以自然语言对话驱动编排，手动编辑作为补充；方案修改产生新版本，旧版本及修改关系必须保留。用户可以自由切换已有版本，切换本身不新增版本；基于所选版本完成修改后，新版本追加至历史末尾，并保留其修改来源。Agent 修改期间以方案为单位禁止手动编辑与再次发起修改，以编辑等待换取清晰的修改顺序，替代并发编辑后再处理冲突；允许查看和切换历史版本，也允许取消当前修改。Agent 完成时提示新版本就绪，保留用户正在查看的历史版本，不因版本切换而改变本次修改基准。取消与故障后必须可靠释放编辑锁，恢复细节按 task-protocol.md 实施并验证。
