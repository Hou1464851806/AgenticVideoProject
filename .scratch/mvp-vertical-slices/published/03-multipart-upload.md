## What to build

用户在项目中选择一个或多个视频，看到逐文件上传进度，传输成功后看到待媒体验证素材。

本票包含该功能所需的持久化、业务接口、界面与必要验证，按用户操作闭环交付。新增入口必须验证项目权限，耗时任务沿用权威任务状态、当前尝试校验和幂等发布；不得把这些要求延后到最终验收。

## Acceptance criteria

- [ ] 真实浏览器通过短期授权直传固定版本 Silo，验证 CORS、ETag、分片分页及完成响应；多文件共享有界并发池，业务 API 不搬运整文件。
- [ ] 服务端持久保存上传身份、对象键及分片事实，签发和完成均检查项目归属；创建时原子预留声明字节与素材名额。
- [ ] 重复创建／完成、创建或完成响应丢失能够核对已有对象；HTTP 成功中的内嵌完成错误被识别，至多保存一份待验证素材。
- [ ] 完成对象后同事务保存待验证素材、媒体验证任务与 Outbox；界面区分传输完成与验证完成，不提前发布为可用素材。

## Verification

真实 Silo 完成小视频上传，注入创建／完成响应丢失和重复请求；检查对象、上传记录与待验证素材数量。
