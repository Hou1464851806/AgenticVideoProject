## What to build

用户给定明确主题和时长，从讲话素材得到一条带片段出处、选取依据与字幕的初始方案。

本票包含该功能所需的持久化、业务接口、界面与必要验证，按用户操作闭环交付。新增入口必须验证项目权限，耗时任务沿用权威任务状态、当前尝试校验和幂等发布；不得把这些要求延后到最终验收。

## Acceptance criteria

- [ ] 业务后端分配新方案身份，同项目可保存多份方案；受控 Agent 从证据及邻近上下文选取观点完整片段，无证据或约束无法满足时解释。
- [ ] 一次成功提交追加一个完整不可变版本，包含成片定义、有序片段、原素材毫秒左闭右开范围、输出规格及映射后的字幕；内部候选与自检不产生版本。
- [ ] 确定性校验权限、引用、范围、时长、输出与硬约束；校验失败不发布方案，修正次数有限，不能执行模型脚本。
- [ ] 编辑取得方案级独占权，固定接纳时基准；结果卡展示来源、范围、依据并可播放源片段，完成不强制改变查看版本，取消／故障释放有效锁。

## Verification

真实 Agent 与人工标注讲话样本验证观点完整性和硬时长；检查非法片段拒绝、重复提交、编辑锁与首次版本唯一性。
